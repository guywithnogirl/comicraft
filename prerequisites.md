Prerequisites

The following knowledge and skills are recommended before developing the ComicCraft application:

Python Programming: Basic to intermediate Python programming, including functions, modules, packages, and working with external libraries.
FastAPI Framework: Basic understanding of building web APIs and FastAPI application structure.
Uvicorn ASGI Server: Familiarity with running and configuring Python ASGI applications using Uvicorn.
HTML, CSS, and Jinja2: Basic knowledge of web-page structure, styling, and server-side templating for developing the application's interface.
Google Gemini API: Understanding of API authentication, API keys, model interaction, and sending requests to Gemini for generative AI functionality.
Hugging Face Diffusers & Stable Diffusion: Basic understanding of diffusion models, pretrained pipelines, and image generation using Diffusers.
PyTorch: Basic familiarity with tensors, neural-network concepts, and automatic differentiation, particularly where PyTorch is used with diffusion models.
FPDF: Basic knowledge of generating and formatting PDF documents programmatically using FPDF.
Git & GitHub: Familiarity with repositories, commits, branches, and pushing/pulling project changes for version control and collaboration.
Python Package & Environment Management: Understanding of pip and isolated Python environments using virtualenv, venv, or Conda.
